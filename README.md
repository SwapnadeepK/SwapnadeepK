### 2. Braille Keypad with Text-to-Speech

An accessibility-focused application designed to help visually impaired users interact with a computer through a Braille keypad and text-to-speech conversion.

**Highlights**
- Braille keypad input for visually disabled users
- Conversion of Braille input into readable text
- Text-to-speech output for accessible interaction
- Designed as an assistive technology project
- Developed as part of an academic project

**Goal:** Build an accessible interface that enables visually impaired users to input and receive information using Braille and speech-based interaction.

**Tech:** `Java17` `Braille` `Text-to-Speech` `Accessibility` `Android Studio`

**Repository:** [Braille_Keypad](https://github.com/SwapnadeepK/Braille_Keypad)
